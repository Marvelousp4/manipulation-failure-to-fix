# v0.2 evidence

RTX 5070 Ti (16 GB), WSL2, Python 3.12.3; exact packages in `requirements-sim.txt`.
CUDA training works. SAPIEN's default CUDA renderer fails to find a supported Vulkan device;
CPU rendering works. Physics remains CPU to match the demonstrations.

Official state BC: 1,000 motion-planning demonstrations, seed 1, 10,000 updates, fixed final
checkpoint (zero-based iteration 9999). Source, dataset and patch hashes are in
`artifacts/checkpoint-provenance.json`. The patch only batches sample transfers; equality is tested.
The 100-demo pilot had 0/10 training-validation success throughout; its log is retained.

The first paired batch was rejected: cached `is_grasped` state differed after prior rollouts.
Scene reconstruction on every reset fixes this; the trained-policy regression test covers it.
Rejected metrics are excluded from the reported experiment. Test seeds and checkpoint stayed fixed.

| Condition | Success | Wilson 95% interval |
|---|---:|---:|
| Clean | 2/50 (4%) | 1.1–13.5% |
| State noise, sigma 0.01 | 2/50 (4%) | 1.1–13.5% |
| Action delay, 2 steps (100 ms) | 1/50 (2%) | 0.4–10.5% |

Noise: one paired regression and one improvement. Delay: two regressions and one improvement.
The clean baseline is too weak for reliable shift-effect claims; reproducing high-performing
BC or testing official ACT/Diffusion Policy is the next research step. No repair claims.
Success terminates early; the cap is 100 steps. Final-step success uses the actual episode endpoint.

13 tests passed, including simulator and trained-policy integration. Repeating nine episodes
matched all episode records and 900 step records exactly on this workstation. Three videos
have 100 frames each at 20 Hz. Fixed seeds do not promise bitwise equality across drivers.
